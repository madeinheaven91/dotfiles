# SwagVim

SwagVim is a minimalistic nightly neovim config that provides zaza. It uses a new native neovim plugin manager.

Partially ripped off [Sylvan Franklin's series](https://www.youtube.com/watch?v=xGkL2N8w0H4).

Features:
- Oil file explorer
- treesitter LSP
- omnicomplete only
- FIXME, TODO, NOTE, HACK and hex color highlighting
- markdown renderer
- wakatime
- vim-tmux navigator
